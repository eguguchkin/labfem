# Лаборатория феминности — сайт

Одностраничный сайт-книга по гайдбуку `guidebook.md`; графика — по `graphics.md`
(qwen-image-3 через Selectel).

## Структура

- `site/` — сам сайт: `index.html`, `styles.css`, `app.js`, `assets/img/*.webp`
- `site_v2/` — альтернативная вёрстка того же содержания: «восемь глав-разворотов»,
  тонкое оглавление сверху, номера глав сбоку; самодостаточна (свои `assets/img`)
- `assets-src/` — сырые PNG из генерации (можно удалить или перегенерировать)
- `tools/manifest.py` — промпты, размеры генерации и целевые ширины ассетов
- `tools/gen.py` — параллельная генерация через CLI pi-image-gen
- `tools/ink.py` — вырезание фона (un-premultiply), trim, ресайз, webp

## Запуск

```bash
cd site && python3 -m http.server 8123 --bind 0.0.0.0
# или альтернативная вёрстка:
cd site_v2 && python3 -m http.server 8124 --bind 0.0.0.0
```

С хоста страница видна только если контейнер запущен с `-p 8123:8123`
(для v2 — `-p 8124:8124`).

## Пересборка графики

```bash
.venv/bin/python tools/gen.py            # всё заново (пропускает готовые)
.venv/bin/python tools/gen.py d1-peon --force
.venv/bin/python tools/ink.py            # перерезать фон у готового сырья
.venv/bin/python tools/ink.py --out=site_v2/assets/img   # то же для вёрстки v2
```

`site_v2/assets/img` — копия нарезки под v2 (favicon.png и og-cover.jpg собраны
из `b11-favicon` и `c1-title` скриптом вручную; при перегенерации пересобрать их тоже).

Модель не отдаёт альфу, поэтому промпты просят плоский фон `#F5F0E8`,
а `ink.py` восстанавливает прозрачность математически
(`C = a·F + (1−a)·B`, фон оценивается max-фильтром).

## Чем заменили генерацию (осознанно)

- фоны A1–A5 — точные hex из палитры + SVG-зерно в CSS: бесшовно и 1 в 1 по цвету;
- линейка B4, маркер B3, иконки соцсетей L1–L4 — inline-SVG/CSS: на 12–24 px
  растр превращается в кашу, а вектор остаётся crisp;
- буквица B9 — живая типографика (`::first-letter`), как советует graphics.md;
- рамка B6, закладка M1 — не использованы: гайдбук помечает их как редкие/опциональные.

## Заменить руками

- Портреты в главе 05 — стилизованные фото авторов (`p1-veronika`, `p2-polina`;
  исходники в `raw/*-art-*.png`, в `assets-src/` лежат обрезанные и с уплощённым
  зерном бумаги копии). Пересобрать: `ink.py p1-veronika p2-polina` — портреты
  единственные идут lossy-webp (флаг `{"lossy": 88}` в манифесте): lossless
  раздувает карандашную микротень до мегабайта.
- Адреса соцсетей и почты в `#ryadom` стоят заглушками (`#`, `hello@femlab.example`).
- Форма подписки никуда не отправляет: JS показывает мягкое подтверждение.
  Когда появится бэкенд — поменять `action` и обработчик в `app.js`.
