Шаблон структура сайта

```
v<N>/
├── spec/                 # ТЗ и материалы (не деплоится)
│   ├── *.md              # возможно brandbook и/или stylebook и прочее
│   └── ref*.{png,jpg}    # референсы стиля
└── site/                 # исходники сайта (собирается в dist/)
    ├── index.html
    └── assets/
        ├── css/style.css # вся палитра и состояния — токенами в :root
        ├── js/main.js
        └── img/          # вся графика (подпапки опциональны)
```
