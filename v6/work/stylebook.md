# Стайлбук «Лаборатория Феминности» — v6

Приложение к брендбуку v6. Всё, что нужно верстальщику: токены, типографика, фактуры,
рамки, компоненты, сетка, состояния. Палитра и состояния — токенами в `:root`.

## 1. Палитра (токены)

```css
:root{
  /* бархат: почти чёрный тёмно-зелёный, три глубины */
  --velvet-deep:#04150d;   /* канвас, самая тьма, виньетки */
  --velvet:#0a2417;        /* основной фон секций */
  --velvet-soft:#123524;   /* подсветка тканей, ховер-подложки */
  /* золото: свет на кромках */
  --gold:#c8a24a;          /* линии, багет, акценты */
  --gold-bright:#e9cd7f;   /* блик, hover, активные элементы */
  --gold-dim:#7d6429;      /* приглушённое золото, номера секций */
  /* поддерживающие пигменты */
  --patina:#6f9c8a;        /* зелень патины; доля площади < 5% */
  --flesh:#e3c3a3;         /* тёплая охра кожи/плодов; точечно */
  --madder:#7e2b26;        /* глубокая марена; одна-две точки на сайт */
  /* текст */
  --ivory:#ece3cf;         /* основной текст на бархате */
  --ivory-dim:#b6ab93;     /* вторичный текст, подписи */
}
```

Правила доли: бархат ≈ 80% площади, золото ≈ 8–10% (линии/рамки/акценты),
слоновая кость ≈ 10% (текст), патина/охра/марена — суммарно < 5%, всегда точечно.
Никаких других цветов; белые (#fff) и чисто-чёрные (#000) значения запрещены.

## 2. Типографика

- **Дисплей/заголовки:** Cormorant (400/500/600 + italic), кириллица. H1 64–96px desktop / 40–56 mobile, line-height 1.05, letter-spacing 0.01em. Заголовки секций — 40–56px, часто с italic-словом внутри.
- **Тело:** EB Garamond (400/500 + italic), 18–20px desktop / 16–17 mobile, line-height 1.75, color --ivory-dim; важные строки --ivory.
- **Надписи-лейблы** («ПСИХОЛОГИЯ × МИФ», номера секций, мета карточек): Cormorant 600, uppercase, 11–13px, letter-spacing .35em, color --gold (или --gold-dim для вторичных).
- **Номера секций** «01…08»: Cormorant italic 500, 14–16px, --gold-dim, перед лейблом: `01 — ЛАБОРАТОРИЯ`.
- **Цитаты:** Cormorant italic 24–32px, --ivory, с золотой линией слева или fleuron-ом над.
- Кернинг отрицательный не использовать; капс только для лейблов, никогда для абзацев.
- Шрифты самохостятся (woff2, подмножества cyrillic + latin) в assets/fonts/.

## 3. Фактуры и слои фона

Слои (снизу вверх):
1. `html` — цвет --velvet-deep.
2. `html::before` — тайл бархата `tex/velvet-tile.webp`, repeat, background-size 512px, лёгкое затемнение к краям страницы общей виньеткой.
3. контент секций.
4. `html::after` — тайл кракелюра `tex/crackle-tile.webp`, repeat, background-size 640px, mix-blend-mode: soft-light, opacity .14, pointer-events:none — поверх всего, как лак старой картины.
5. виньетки секций: radial-gradient по краям каждой полноэкранной панели (transparent 55% → --velvet-deep 100%).

Внутри полотен-картин допускается собственная виньетка и тёплый световой центр.
Золочение (багет, fleuron, нимбы) заливается тайлом `tex/gold-tile.webp` через mask/background-clip, чтобы золото было фактурным, не плоским.

## 4. Рамки, арки, орнамент

- **Арка (altarpiece):** верх панели скруглён `border-radius: 50% 50% 0 0 / 30% 30% 0 0`; двойной багет: внешняя линия 1px --gold-dim + внутренняя 1px --gold с отступом 6px; между ними тень `box-shadow: 0 0 0 1px` не использовать — только две живые линии и тёмный зазор.
- **Прямоугольные полотна:** багет 1px --gold-dim снаружи, 8px тёмного зазора, 1px --gold внутри; углы прямые (контраст с арками), но с лёгкой внутренней виньеткой.
- **Разделитель секций:** волосяная линия --gold-dim по центру + fleuron `orn/fleuron.webp` 28–36px поверх линии; по бокам линии затухают (mask-gradient).
- **Нимб/медальон:** круглая рама для оптик-ронделей: 1px --gold + радиальное золотое свечение за краем (box-shadow 0 0 40px rgba(200,162,74,.18)).
- Скругления elsewhere: только малые (4–8px) у кнопок-«табличек»; никаких pill-форм.

## 5. Компоненты

- **Кнопка-табличка:** прямоугольник с багетом 1px --gold, фон прозрачный (или --velvet-soft при hover), текст Cormorant 600 uppercase ls .25em 13px --gold-bright; padding 14px 28px; hover: фон --velvet-soft + лёгкое золотое свечение; active: без сдвига, только яркость. Никаких заливок градиентом.
- **Карточка программы:** арочное полотно 4:5, изображение внутри арки, под ним имя программы (Cormorant 28–32px), одна строка сути (EB Garamond italic), мета-лейбл (формат · длительность · город), статус-строка («набор открыт» — --gold; «в подготовке» — --ivory-dim). Hover: картина светлеет на 4% и багет переходит в --gold.
- **Портрет автора:** арка 2:3, дуотон-сепия поверх бархата (тени --velvet, света --flesh/ivory), зерно и виньетка; имя Cormorant 24px, регалии EB Garamond 15px --ivory-dim.
- **Цитата-панель:** по центру, fleuron над, Cormorant italic, подпись лейблом.
- **Форма подписки:** поле-«пергамент» (фон tex/parchment-tile.webp, opacity 90%, текст --velvet-deep), кнопка-табличка рядом; после отправки — строка «письмо дойдёт… спасибо» italic.

## 6. Сетка и ритм

- Контейнер 1160px desktop / 92vw mobile; вертикальный ритм секций: полноэкранные панели (min-height 100svh) чередуются с «простенками» 60–70svh.
- Парность: текст слева / полотно справа, зеркально в следующей секции; мобильный — всегда колонка: лейбл → заголовок → полотно → текст.
- Воздух: между блоками внутри секции ≥ 96px desktop / 56px mobile; секции разделены линией с fleuron, никогда — цветной плашкой.
- Асимметрия разрешена и желательна: полотна могут выступать за контейнер на 8–12% ширины, перекрываясь с виньеткой.

## 7. Состояния и движение (база, без JS-эффектов)

- hover изображений: brightness 1.04 + багет --gold; transition 400ms ease.
- hover ссылок/кнопок: цвет --gold-bright, подчёркивание волосяной линией с расширением от центра.
- focus-visible: outline 1px --gold-bright offset 4px.
- prefers-reduced-motion: все transition ≤ 1ms.
- Этап 4 добавит: параллакс полотен, reveal-проявление «как проявка фотографии», мерцание свечного света, дрейф кракелюра — список предложим на этапе 3.

## 8. Можно / нельзя

Можно: полутени, зерно, неровные края золота, рукописные детали багета, асимметрия, многоточия.
Нельзя: плоские заливки золотом без фактуры, белые карточки, тени «material», стеклянные blur-панели, иконки из icon-сетов, эмодзи, капс в абзацах, более одного акцентного цвета на секцию, любые рамки толще 1px (багет рисуется двумя линиями, не толщиной).
